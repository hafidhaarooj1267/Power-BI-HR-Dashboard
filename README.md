# HR Analytics Dashboard

## Project Overview

This is an HR Analytics Dashboard built using **Power BI**. The dashboard provides key insights into employee attrition, job satisfaction, salary trends, and demographic patterns within the company.

I worked with real company data containing multiple columns such as employee age, gender, education, job role, salary, years at company, attrition status, and job satisfaction scores.

---

## My Approach

### 1. Data Cleaning & Storage (Excel)
- Used **Excel** for initial data cleaning
- Handled missing values, removed duplicates, and standardized formats
- Stored cleaned data for further processing

### 2. ETL Process (Power Query)
- Connected Excel data to **Power BI**
- Used **Power Query** for:
  - Data transformation
  - Merging and appending tables
  - Creating calculated columns
  - Filtering and sorting relevant data

### 3. Calculations & Measures (DAX)
- Created **DAX formulas** for key metrics:
  - Attrition Rate
  - Average Salary
  - Average Age
  - Count of employees
- Built custom measures for dynamic filtering

### 4. Dashboard Design (Power BI)
- Designed interactive **HR Dashboard** with:
  - KPI cards (Total Employees, Attrition, Attrition Rate, Avg Age, Avg Salary)
  - Attrition breakdown by gender, education, age group, salary, job role
  - Job Satisfaction chart by role
  - Years at Company attrition trend
